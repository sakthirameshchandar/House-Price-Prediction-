# 🏠 House Price Prediction

## 📌 Project Overview
House Price Prediction is a Machine Learning project that predicts the price of a house based on various features such as area, number of bedrooms, location, and other related factors.  
This project uses Linear Regression to build the prediction model.

The goal of this project is to understand how regression works and how different factors influence house prices.

---

## 🚀 Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Linear Regression model implementation
- Model evaluation using regression metrics
- Price prediction for new input data

---

## 🛠️ Technologies Used
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib / Seaborn**
- **Scikit-learn**
- **Jupyter Notebook**

---

## 📂 Dataset
- Dataset used: `HPPM.csv`
- The dataset contains house-related attributes such as:
  - Area
  - Number of rooms
  - Location
  - Price (target variable)

---

## ⚙️ Model Used
- **Linear Regression**
- Since this is a regression problem, **accuracy is not used**.
- Model performance is evaluated using:
  - Mean Absolute Error (MAE)
  - Mean Squared Error (MSE)
  - R² Score

---

## 📊 Evaluation Metrics
| Metric | Description |
|------|------------|
| MAE | Average absolute error |
| MSE | Average squared error |
| R² Score | Measures goodness of fit |
